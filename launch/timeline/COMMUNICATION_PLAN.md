## Internal communication plan

Internal audiences need **one truth** before customers: what launches, what is preview, and who owns escalations.

**T-2 weeks:** Launch all-hands (30 min)—walk [LAUNCH_NARRATIVE](../LAUNCH_NARRATIVE.md) §1–3, show [TIMELINE](./TIMELINE.md) L-day schedule, introduce war room roster. Distribute link to [CHECKLIST](./CHECKLIST.md) and [RISK_MITIGATION](./RISK_MITIGATION.md).

**T-1 week:** Function-specific briefings—Engineering (freeze rules), Support (FAQ + [press-kit FAQ](../../press-kit/FAQ.md)), Sales (demo script from [homepage copy](../../website/copy/homepage.md)), Partner PM ([partner-program](../../partner-program/PROGRAM_OVERVIEW.md)).

**L-1 day:** Slack/Teams `#launch-war-room` (placeholder) pinned with URLs, on-call, status page. CEO note: calm, precise—no overpromising preview modules.

**L-day:** Hourly internal pulse in war room; EOD summary vs [success metrics](./LAUNCH_OVERVIEW.md#launch-success-metrics).

**D+7:** Retro—wins, doc gaps, metric review; thank beta cohort publicly in internal note.

**Artifacts:** internal FAQ (mirror [press-kit FAQ](../../press-kit/FAQ.md)), slide with four pillars ([messaging](../../brand/MESSAGING_PILLARS.md)), forbidden phrases list (“only,” unverified ROI %).

## External communication plan

External comms **prove** the Retail OS story with links to docs—not hype without URLs.

| Phase | Message theme | Proof links |
|-------|---------------|-------------|
| **Pre-launch (T-2 to L-1)** | “Something’s coming” / developer early access | Teaser, waitlist optional |
| **L-day** | Ordella is the Retail Operating System | ordella.com, docs, video |
| **D+1–7** | Build on Ordella | [developer-onboarding](../../developer-onboarding/OVERVIEW.md) |
| **D+8–30** | Ecosystem + proof | partners, case studies (draft) |

**Audiences:**

- **Developers** — technical blog, API quickstart, sandbox CTA  
- **Partners** — program tiers, apply now, certification path  
- **Retailers** — outcomes, demo request, compliance docs for enterprise  
- **Press** — embargo release + [boilerplate](../../press-kit/COMPANY_BOILERPLATE.md)  
- **Investors** — private deck, not mass email ([pitch deck](../../pitch-deck/DECK_STRUCTURE.md))

Label **preview** features in all external posts when applicable ([ROADMAP_PREVIEW](../../beta-program/ROADMAP_PREVIEW.md)).

## Timing and sequencing (L-day)

```
08:00  Website live
08:15  Docs + changelog
08:30  Developer blog + portal
09:00  Video public
09:30  Partner announcement
10:00  Press release
10:00+ Social wave (staggered)
14:00  Retailer/demo campaign push
```

**Do not** announce marketplace revenue share rates not in contract. **Do not** publish founder bio with unfilled [FOUNDER_BIO](../../press-kit/FOUNDER_BIO.md) placeholders.

**Crisis comms:** pause scheduled social on P0; use [RISK_MITIGATION](./RISK_MITIGATION.md) contingency templates.
