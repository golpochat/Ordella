# Apps

Deployable applications in the Ordella monorepo.

| App | Stack | Purpose |
|-----|-------|---------|
| `api` | NestJS | Modular monolith API (all domain modules) |
| `admin` | Next.js | Admin dashboard |
| `pos` | Next.js | Point of sale |
| `customer-app` | Next.js | Customer web ordering |
| `driver-app` | Next.js | Driver delivery app |
