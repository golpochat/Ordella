---
title: Onboarding wizard
description: Steps to complete initial setup.
---

The wizard guides you through:

1. **Started** — tenant created
2. **Menu** — categories and products
3. **POS** — register configuration
4. **Delivery** — optional delivery zones
5. **Payments** — payment methods
6. **Complete** — go live

Complete each step from Admin or via API endpoints under `/api/v1/onboarding/step/*`.
