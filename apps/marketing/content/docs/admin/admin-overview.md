---
title: Admin overview
description: Navigate the Ordella admin dashboard.
---

The admin dashboard (`/admin` UI) is the control center for each tenant:

- **Products** — catalog, categories, modifiers
- **Orders** — list, detail, status overrides
- **Inventory** — stock and adjustments
- **Promotions** — campaigns (when enabled)
- **Reports** — sales and operations
- **Settings** — business, branding, billing, hours

Access requires an **admin** or **manager** role.
