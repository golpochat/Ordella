Growing from one site to many exposes gaps in single-location tools.

## Checklist

| Requirement | Ordella |
| --- | --- |
| Per-location catalog or shared catalog | ✓ |
| Role-based staff access | ✓ |
| Centralized reporting | ✓ |
| Plan limits by business location & orders | ✓ |
| Custom domains per brand | ✓ |

<Callout variant="info">
  [Pro plan](/pricing) supports unlimited business locations and higher monthly order limits for scaling brands.
</Callout>

## Rollout tips

1. Pilot one location on the new stack before migrating everyone.
2. Standardize modifiers and naming so reporting compares fairly.
3. Train managers on admin roles before opening self-serve changes to staff.
