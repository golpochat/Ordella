# Ordella Public Docs — Branding

Guidelines for presenting Ordella documentation at **docs.ordella.com**.

## Product name

- **Ordella** — always capitalized; never “ordella” in titles.
- Tagline: **The Retail Operating System**

## Voice (summary)

Professional, clear, and confident. See [tone.md](./tone.md) for full writing rules.

## Visual identity (placeholder)

| Element | Value |
|---------|--------|
| Primary color | `#0F766E` (teal) — placeholder |
| Accent | `#F59E0B` (amber) — placeholder |
| Font (headings) | Inter — placeholder |
| Font (body) | Inter — placeholder |
| Logo | Ordella wordmark — placeholder asset path: `/assets/logo.svg` |

## Code and API presentation

- Base URL: `https://api.ordella.com/v1`
- Use monospace for endpoints, headers, and JSON.
- HTTP methods in uppercase: `GET`, `POST`, `PUT`, `DELETE`.

## Diagrams

- Prefer accessible diagrams with alt text when rendered to HTML.
- Architecture diagrams should align with [Architecture](../architecture/high-level-architecture.md) section naming.
