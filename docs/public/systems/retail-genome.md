# Retail Genome Project

Retail Genome: entity resolution, behavioral features, and intelligence graph for retail AI.

Retail Genome links customers, products, locations, and events into a unified intelligence graph for analytics and AI.

Feature stores expose curated signals to Promotions, AI Assistant, and partner apps with consent boundaries.

Data scientists integrate via Data Lake exports and documented feature APIs—expanded reference material is planned.
