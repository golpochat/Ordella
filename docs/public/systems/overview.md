# Systems Overview

Map of Ordella platform systems and how they fit together for operators and integrators.

Ordella is organized into composable systems—each with APIs, admin surfaces, and event contracts—rather than monolithic modules.

Core operations (catalog, orders, locations) feed commerce engines (pricing, promotions, loyalty) and intelligence layers (AI, Data Lake, Retail Genome).

This overview helps architects and operators choose the right modules and understand cross-system dependencies before deep dives.
