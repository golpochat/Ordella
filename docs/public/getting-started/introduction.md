# Introduction to Ordella

Ordella is a multi-tenant Retail OS that unifies store operations, commerce, intelligence, and enterprise governance in one platform.

Whether you run a single location or a global franchise, Ordella provides a consistent tenant model, API-first integrations, and modular systems that share data through a central event stream.

This introduction orients new readers before they dive into developer guides, system modules, or architecture documentation.

Start here if you are evaluating Ordella, onboarding a technical team, or preparing an enterprise security review.
