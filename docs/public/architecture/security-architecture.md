# Security Architecture

Identity, encryption, network boundaries, and defense-in-depth for Ordella.

Security architecture centers on zero-trust service communication, tenant-scoped authorization, and encryption in transit and at rest.

Administrative actions are audited; integrators use scoped API credentials with rotation and IP allow lists where required.

Compliance frameworks (SOC 2, ISO 27001, PCI) map to specific controls documented in the Compliance section.
