# Rate Limits

Fair-use API limits, throttling behavior, and best practices for high-volume clients.

Rate limits protect tenant isolation and shared infrastructure. Limits apply per API key or user session within a tenant.

When exceeded, the API returns HTTP 429 with retry guidance in headers where available. Batch reads and webhooks reduce unnecessary polling.

Enterprise agreements may include higher ceilings; contact sales for dedicated capacity planning.
