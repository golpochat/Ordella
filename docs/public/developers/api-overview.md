# API Overview

Introduction to the Ordella REST API: versioning, formats, and resource groups.

The REST API is the primary integration surface at https://api.ordella.com/v1. Resources map to product modules such as orders, inventory, loyalty, and the Event Bus.

Responses use JSON with a consistent success envelope. Errors return appropriate HTTP status codes and machine-readable messages.

Consult the API Reference hub for REST, planned GraphQL, SDKs, and webhooks. Rate limits protect platform stability.
