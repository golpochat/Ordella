# POS Integration Guide

Connect point-of-sale clients to Ordella for catalog, orders, payments, and offline sync.

This guide walks integrators through registering POS devices, authenticating with tenant-scoped credentials, and synchronizing catalog and order data with the Operations Core.

Ordella supports online and offline POS scenarios: devices can queue transactions locally and reconcile when connectivity returns, using idempotent order APIs and conflict rules documented below.

Use this guide alongside the [Authentication](../developers/authentication.md) and [Webhooks](../developers/webhooks.md) docs for production rollouts.
