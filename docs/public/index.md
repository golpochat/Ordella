# Ordella Documentation

Welcome to the public documentation for **Ordella** — the Retail Operating System for unified operations, commerce, intelligence, and enterprise control.

Ordella helps retailers run stores, sell across channels, automate workflows, and meet enterprise compliance requirements from a single multi-tenant platform. This site is the authoritative guide for operators, developers, partners, and security reviewers evaluating or building on Ordella.

## How this documentation is organized

Documentation is grouped into seven top-level areas, reflected in the site navigation and sidebar:

| [Developers](./developers/api-overview.md) | Engineers | APIs, auth, webhooks, SDKs |
| [Guides](./guides/pos-integration.md) | Integrators | Step-by-step channel integrations |

Configuration for this site lives in [`_config/`](./_config/) (`navigation.json`, `sidebar.json`, `search.json`).

## Who these docs are for

- **Retail operators** configuring catalog, inventory, promotions, and locations.
- **Developers** integrating POS, storefronts, mobile apps, or custom backends.
- **Data and analytics teams** using the Event Bus, Data Lake, and Retail Genome.
- **Enterprise buyers** reviewing security, residency, and deployment architecture.
- **Technology partners** building apps and services on the Ordella marketplace.
